## Vieningos retransliatorių vardų sistemos privalumai

1. Paprasta nustatyti retransliatoriaus vietą pagal jo vardą
2. Paprasčiau sudaryti žinutės pristatymo kelią
3. Galima suprasti žinutės gavimo kelią nenaudojant žemėlapio
4. Lengviau naudotis paieška ir filtruoti kontaktus
5. Vardų sistema sudaro rimto tinklo įspūdį
6. Vieninga vardų sistema siunčia pozityvią žinutę apie vieningą Lietuvos MeshCore bendruomenę

## Formatas

Retransliatoriaus vardą rekomenduojama formuoti pagal šią struktūrą:

```
Retransliatorius: LT-{Kodas} {Mikrorajonas|Vietovė} {ID-4} [Kryptis]
Stebėtojas: LT-{Kodas} {Mikrorajonas|Vietovė} {ID-2} OBS
```

- `LT-` - Lietuvos [dviraidis ISO 3166-1 kodas](https://lt.wikipedia.org/wiki/ISO_3166-1)
- `Kodas` - miesto kodas (apskrities centro miesto ribose) arba apskrities kodas (už miesto ribų)
- `Mikrorajonas` -  miesto mikrorajonas, miesto gyvenvietė, miesto žymi vieta
- `Vietovė` - apskrities miestas (išskyrus apsk. centrą), miestelis, gyvenvietė, kaimas, žymi vieta; gali būti iš kelių žodžių
- `ID` - retransliatoriaus keturių simbolių identifikatorius. Stebėtojo varde naudojami pirmieji du šio ID simboliai ir sufiksas `OBS`.
- `Kryptis` (neprivaloma) - retransliatoriaus spinduliavimo kryptis: N,NE,E,SE,S,SW,W,NW
